# Archived — instruction checks moved

RuleMeter is retired as a standalone product and CLI. Its instruction discovery, source topology, exact duplicate/overlap analysis, owner decisions and review delta are consolidated into [Starter Series create-starter](https://github.com/starter-series/create-starter#instruction-checks).

Use `starter-series check --instructions` in create-starter. The existing `audit-instructions` command and MCP `audit_instructions` remain supported there.

Please open [issues and development requests in create-starter](https://github.com/starter-series/create-starter/issues). This repository is retained as read-only historical source; no further standalone releases are planned. The npm package was not published at retirement, and this source package is marked private.
